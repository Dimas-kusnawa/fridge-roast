A program that writes one roast line to `/output/entry.txt` (123 characters, inside the 1–200 character gate): "My smart fridge updated its firmware at 2 a.m. and now it won't open until I agree to the new terms. The milk is a hostage." A forced firmware update locks the door behind a terms-of-service wall, so the food inside becomes a hostage — the punch lands in the last sentence, and the joke only works on a smart fridge.

## Run it

```sh
python3 main.py
```
